# Demo 主响应 / 功能演示

主办方要「Demo 主响应文件」时，按表单要求从下面三份里选。

## 1. 功能总览录屏

`demo-tour.mp4`

- 约 62 秒，1280×800，H.264；
- 覆盖：开场动画 → 自动登录 → 本地命中 → 等价问法 → 画鹈鹕（本地工具）→ 未命中提示 → 新建聊天 → 问答库详情 → 共享知识库 → Work 工作台 → 复用方法 → 审核与治理 → 用户管理 → 用量与成本 → 设置 → 切换普通用户身份。

## 2. 主响应短录屏

`demo-main-response.mp4`

- 15 秒，专注展示「提问 → 命中 → 0 次云端调用」和画鹈鹕。

## 3. 单文件离线 Demo

`demo-standalone.html`

- 0.7 MB，双击即可打开，不需要服务器、不需要网络；
- 内置 1,003 条问答，浏览器内匹配；
- 含「画个骑车的鹈鹕」的完整 HTML 回答。

## 说明

主响应 = 本地问答库命中：直接返回已收录答案，标记命中方式与「0 次云端调用」；未命中不调用大模型。
