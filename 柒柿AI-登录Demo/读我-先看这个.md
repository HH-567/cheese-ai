# 柒柿 AI · 身份核验（可运行包）

一个把「开机动画」做成真登录页的静态站点：**六幕片头 → 第 2 幕输账号口令 → 核验通过 →
终幕用真名欢迎 → 进访问控制台**。纯静态、零依赖、不联网、不需要装任何东西。

## 怎么打开

- 双击 **`打开登录页.cmd`**（会用默认浏览器打开）
- 或者直接双击 **`index.html`**

要求：Chrome / Edge / Firefox 任一较新版本。**不需要 Node、不需要 Python、不需要起服务。**

演示账号：**`qishi` / `qishi2026`**（登录框里那行虚线框点一下就自动填）。
也可以点「登记新身份」自己建一个 —— 账号存在你这台机器的浏览器里。

## 玩一遍的话，会看到这些

| 你做什么 | 会发生什么 |
|---|---|
| 第 1 幕点「授予访问权限」 | 顺带解锁浏览器音频（所以第一句台词可能被自动播放策略吃掉，属正常） |
| 第 2 幕口令输错 | 表单抖一下 + 红字「还可尝试 N 次」，**动画停在原地**，可以继续试 |
| 连错 5 次 | 锁定 15 秒 → 1 分钟 → 5 分钟 → 15 分钟，倒计时期间提交被拒 |
| 口令对 | 身份卡回填真实姓名/编号/权限，720ms 后动画继续，终幕变成「欢迎 你的名字 访问」 |
| 右上角 SKIP / Esc | 跳过动画，但门还在：落到纸面上的一张独立登录卡（同一套校验） |
| 登录后 | 访问控制台：身份档案、本次会话、最近核验记录；右上角可「重播开场」「退出登录」 |

## 里面有什么

    index.html                 唯一的页面
    打开登录页.cmd              双击即开
    assets/
      qishi.config.js          ★ 要改的东西都在这：品牌名、演示账号、声音、锁定阶梯

## 想改什么，改哪里

| 想改 | 改哪 |
|---|---|
| 品牌名、副标题、终幕小字 | `assets/qishi.config.js` 的 `brand` |
| 演示账号 | `assets/qishi.config.js` 的 `demo`（只在本地库第一次创建时写入） |
| 品牌色（片头光标 / 终幕高光都跟着走） | `assets/qishi.config.js` 的 `brand.accent` |
| 片头声音开关、倍速、是否可跳过 | `assets/qishi.config.js` 的 `intro` |
| 失败几次锁、锁多久 | `assets/qishi.config.js` 的 `auth` |
| 台词 | 覆盖 `vendor/dsh-boot-suite/lib/assets/voices/f/line-6.mp3` 即可，不用改代码 |
| 登录之后那一页 | `assets/ui/qishi-app.js` |

调试参数（加在地址后面，都不影响默认体验）：
`?skipintro=1` 不播片头直接进登录卡 · `?nosound=1` 静音 · `?speed=1.6` 倍速 ·
`#demo=auto` 第 2 幕自动填演示账号并提交。

## 安全边界（请勿跳过）

账号库在浏览器的 `localStorage` 里，口令用 **PBKDF2-SHA256（随机盐、12 万次迭代）**
存哈希，能完整演示注册 / 核验 / 失败锁定 / 会话 / 审计的真实流程。但它**不构成安全边界**：

- 同一台机器上的人可以直接改 `localStorage`，或者改这段 JS 把自己放进去；
- 会话令牌的签名密钥也在同一台机器上；
- 口令是在前端校验的。

**它适合 demo、内网工具、离线样机、接入前的交互样板；要防人就得换成后端适配器** ——
`assets/auth/auth-http.example.js` 已经把接口契约和坑（HttpOnly Cookie、CSRF、
失败锁定放服务端、防账号枚举）写好了，`docs/接入说明.md` 里有分步做法。
